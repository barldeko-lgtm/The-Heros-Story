# Редактирование PNG-карты

Файл `prototype_02_hex_layout.png` — источник раскладки текущей карты 20 × 15. Игра считывает точный цвет в центре каждого гекса и по нему определяет тип клетки.

## Палитра

| Назначение | HEX | RGB |
|---|---|---|
| Равнины | `#9EAD78` | `158, 173, 120` |
| Лес | `#4F7453` | `79, 116, 83` |
| Холмы | `#9A8160` | `154, 129, 96` |
| Дорога | `#D6BD7A` | `214, 189, 122` |
| Стартовый город | `#887258` | `136, 114, 88` |
| Старт героя | `#E04B5A` | `224, 75, 90` |
| Средний город | `#716985` | `113, 105, 133` |

## Правила

- Не изменяйте размер PNG (`615 × 545`) и не двигайте сетку.
- Используйте точные цвета из таблицы или берите цвет пипеткой с уже существующего гекса.
- Чёрные контуры можно оставить: игра читает центральный пиксель каждого гекса.
- Должен существовать ровно один ярко-красный гекс старта героя.
- Его должны окружать шесть коричневых гексов стартового города.
- Средний город должен состоять из семи фиолетовых гексов: центр и шесть соседей.
- Жёлтая дорога должна быть одной непрерывной цепочкой без ответвлений и касаться обоих городов.
- Не используйте JPEG, полупрозрачную кисть, размытие или изменение оттенков.

После сохранения PNG дайте Godot переимпортировать файл или перезапустите проект. Неизвестный цвет не превращается молча в равнину: декодер сообщает координату проблемного гекса.

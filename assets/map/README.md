# Редактирование PNG-карты

Файл `prototype_02_hex_layout.png` — источник раскладки текущей игровой карты 26 × 15. Игра считывает точный цвет только в техническом центре каждого игрового гекса и по нему определяет тип клетки.

## Палитра

| Назначение | HEX | RGB |
|---|---|---|
| Равнины | `#9EAD78` | `158, 173, 120` |
| Лес | `#4F7453` | `79, 116, 83` |
| Холмы | `#9A8160` | `154, 129, 96` |
| Дорога | `#D6BD7A` | `214, 189, 122` |
| Стартовый город | `#887258` | `136, 114, 88` |
| Старт героя | `#E04B5A` | `224, 75, 90` |
| Средний город | `#716985` | `113, 105, 133` |

## Правила

- Не изменяйте размер PNG (`1448 × 1086`) и не двигайте сетку без одновременного обновления source-геометрии в `data/map/prototype_02_map.tres`.
- Текущая картинка визуально содержит дополнительный нижний декоративный гекс в каждой чётной колонке. Эти 13 нижних гексов не входят в логическую карту; игровой прямоугольник остаётся 26 × 15 = 390 гексов.
- Внутри гекса визуальная заливка может иметь оттенки, но **центральный технический пиксель игрового гекса обязан иметь точный цвет из таблицы**. Не закрашивайте эти центральные пиксели градиентом или полупрозрачной кистью.
- Чёрные контуры можно оставить: игра читает только центральный технический пиксель каждого игрового гекса.
- Должен существовать ровно один ярко-красный гекс старта героя. Это технический маркер центра: в игровых данных его местность нормализуется в `starting_city`.
- Его должны окружать шесть коричневых гексов стартового города, поэтому игровой стартовый город состоит из семи гексов местности `starting_city`.
- Средний город должен состоять из семи фиолетовых гексов: центр и шесть соседей.
- Жёлтая дорога должна быть одной непрерывной цепочкой без ответвлений и касаться обоих городов.
- Не используйте JPEG. Визуальные градиенты допустимы вне технических центральных пикселей.

После сохранения PNG дайте Godot переимпортировать файл или перезапустите проект. Неизвестный цвет не превращается молча в равнину: декодер сообщает координату проблемного гекса.

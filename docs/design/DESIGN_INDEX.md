# The Hero’s Story — Modular Design Index

**Status:** Draft  
**Purpose:** entry point and map for the modular game-design documentation that will gradually replace the monolithic role of `The_Heros_Story_Concept_Design_Pillars_v2.7_EN.md`.

## What this document covers

- the list of modular design documents;
- the responsibility and boundaries of each document;
- the order and priority for future review;
- migration status while ideas are redistributed from the current concept document.

## What this document does not cover

- detailed mechanics;
- balance values and formulas;
- implementation details;
- Prototype 0 scope or current code state.

## Migration rule

`docs/The_Heros_Story_Concept_Design_Pillars_v2.7_EN.md` remains an active reference during migration.

Content is **not copied automatically**. Each idea must be reviewed and then:
- moved into the appropriate modular document;
- rewritten or split if necessary;
- expanded only where useful;
- or intentionally discarded if it no longer strengthens the project.

After migration is complete and verified, the old concept document may be marked as archived/superseded. It should not be deleted automatically.
